# ラジオ体操ヒーローズ 展示・ランキング（試作）

## PDFスライドショー（追加機能）

1. PowerPointの「名前を付けて保存」などから、スライドをPDF形式で保存します。
2. アプリの「スタッフ管理」→「PDFスライドショー」でPDFを選びます（100MBまで）。
3. 「1ページの表示時間」を2～120秒で設定します。初期値は8秒です。
4. 「展示画面へ」でランキングと並べて表示します。最後のページの後は先頭へ戻ります。
5. スタッフ画面で一時停止・自動再生・前へ・次へを操作できます。「動画を展示」「PDFを展示」で切り替えます。

スタッフ画面や非表示タブでは自動ページ送りを止めます。PDFはPC内のブラウザで読み込み、外部へアップロードしません。再読み込み後は選び直してください。パスワード保護PDFには対応していません。PDF化するとPowerPointのアニメーション・音声・埋め込み動画は再生されません。

### 配布・更新時の注意

従来のファイルに加え、`slideshow.mjs`と`vendor`フォルダー全体を各PCへコピーしてください。PDF表示に使うMozilla PDF.js 5.6.205を同梱しています（Apache-2.0、`vendor/pdfjs/LICENSE`）。追加インストールやインターネット接続は不要です。

サーバーが動作中の場合はCtrl+Cで停止してから`node server.cjs`で再起動し、ブラウザでCtrl+F5を押してください。既存のランキング保存形式は変更していません。

既存ゲームとは別のアプリです。ゲームのソースや公開設定は変更しません。

## 起動

Node.js があるPCで、このフォルダーから `node server.cjs` を実行し、`http://127.0.0.1:4180` を開きます。終了は Ctrl+C。

1. スタッフ管理で紹介動画を選ぶ（MP4推奨）。映像はループします。最初は消音です。
2. 公開に同意した参加者のニックネーム・スコア・日付を入力。
3. 展示画面に戻すと本日のTOP10が表示されます。全画面表示が使えます。
4. イベント終了時に、スタッフ管理からCSVを出力します。日付を絞るか「全日程」を選びます。

## 保存・順位

- localStorage に保存します。同じPC・ブラウザ・URL（ポート含む）でのみ再利用できます。プライベートブラウジングは避けてください。
- スコアは同じURLの別タブにも反映しますが、動画は選んだタブだけで再生します。
- 紹介動画は端末のファイルを参照し、アップロードも永続保存もしません。再読み込み後は選び直してください。
- 本日はPCのローカル日付で判定。点数の降順、同点は登録順、順位は1・1・3方式。表示件数は最大10件です。
- 同じニックネームも別の記録として扱います。重複はスタッフが編集・削除してください。
- 研究同意とランキング公開同意は別です。本名や個人情報を入力しないでください。
- モード・時間・ゲームバージョンが異なる結果を混在させない運用にしてください。
- CSVはExcel向けUTF-8 BOM付き。数式として解釈されやすい文字列は先頭にアポストロフィを付けます。

## 試作の制限

スタッフ画面に認証はありません。アクセスできる人は登録・編集・削除できます。保存データは改ざん防止されません。会場の管理PCで使用してください。
複数PC共有・ゲームからの自動送信・認証・動画の恒久保存・CSV再取り込みは未実装です。公開用サービスに進める際はサーバー保存とスタッフ認証を追加してください。
ブラウザデータを削除すると記録も消えます。CSVをこまめに保存してください。

## 展示・ランキングアプリのローカル利用手順
Vercelは使わず、アプリと紹介動画を各PCにコピーして利用します。ランキングはPCごとに保存され、別PCとは自動共有されません。
1．最初の準備
各PCにNode.jsとブラウザを用意します。コマンドプロンプトで確認してください。
node --version
番号が表示されれば準備完了です。認識されない場合は、Node.js公式サイトからインストールし、コマンドプロンプトを開き直してください。
2．アプリを各PCにコピー
GitHubのリポジトリで「Code」→「Download ZIP」を選び、ダウンロード後に「すべて展開」します。USBメモリーでフォルダー一式を渡しても構いません。

以下のファイルを同じフォルダーに置いてください。
heroes-showcase/
  index.html
  style.css
  app.js
  server.cjs
  README.md
npm installは不要です。紹介動画も各PCにコピーしてください。動画は別のフォルダーでも構いません。
3．起動する
1. エクスプローラーでserver.cjsがあるフォルダーを開きます。
2. アドレス欄にcmdと入力してEnterを押します。
3. 次のコマンドを実行します。
node server.cjs
起動成功の表示が出たら、コマンドプロンプトを閉じずに、ブラウザで次を開きます。

http://127.0.0.1:4180

このURLは「使用中のPC自身」を指します。各PCで起動操作が必要です。
4．紹介動画を設定する
1. 「スタッフ管理」を押します。
2. 動画ファイルの選択から、PC内の紹介動画を選びます。
3. 必要なら「動画の音声を出す」をチェックします。
4. 「展示画面へ」→「全画面表示」を押します。
動画はループ再生されます。これはクラウドへのアップロードではなく、PC内の動画を読み込む操作です。

再読み込みやブラウザ終了後は、動画を選び直してください。
5．スコアを入力する
スタッフ管理で、ニックネーム・スコア・プレイ日を入力します。本人に公開の同意を確認してから登録してください。本名は使わないでください。

ゲームからの自動送信はありません。スタッフが結果画面を見て入力します。当日の記録が「本日のTOP10」の対象です。
6．CSV保存と終了
1. スタッフ管理で日付を指定するか「全日程」を選びます。
2. 「表示中のデータをCSV出力」を押します。
3. CSVがダウンロードされたことを確認します。
4. コマンドプロンプトでCtrl+Cを押して終了します。
複数PCで使う場合は、CSVのファイル名にPC-Aなどを付けると区別できます。

CSVはExcelなどで集計できますが、アプリへの再取り込み機能はありません。
保存に関する注意
- スコアはブラウザ内に保存されます。フォルダーをコピーしても記録は移りません。
- 次回も同じPC・ブラウザ・プロフィール・URLを使ってください。
- プライベートブラウジングは避けてください。
- ブラウザのデータ削除で記録も消えるため、CSVをこまめに保存してください。
- スタッフ認証はないため、管理PCで利用してください。
- 準備後の動画再生・スコア入力・CSV出力には、インターネット接続は不要です。
起動できない場合
EADDRINUSEは4180番ポートが使用中という意味です。二重起動せず、既に起動した自分のサーバーを確認してください。

使用中なのに開けない場合は、次の結果を担当者に伝えてください。
netstat -ano | findstr :4180
用途が分からないプロセスを強制終了しないでください。
